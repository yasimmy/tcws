Гайд по деплою на Vercel для yasimmy/tcws
=========================================

Git-репозиторий:
- yasimmy/tcws
- Ветка: main

Что вписывать в поля Vercel New Project:

1) Project Name
- tcws

2) Application Preset
- Vite (если есть в списке)
- Если Vite нет, выбери Other

3) Root Directory
- ./

4) Build Command
- npm run build

5) Output Directory
- dist

6) Install Command
- npm install

7) Environment Variables
- Пока оставь пусто (для базового деплоя переменные не нужны)
- НЕ добавляй EXAMPLE_NAME / I9JU23NF394R6HH, если в коде это явно не используется

8) Environments
- Production and Preview

После деплоя:
- Открой URL проекта из Vercel
- Проверь главную страницу и /download
- Убедись, что статика грузится и переходы по страницам работают

Если билд упал:
- Проверь Build Command: npm run build
- Проверь Output Directory: dist
- Запусти деплой заново
