# TubeCAD Website

Официальный сайт для TubeCAD - профессионального CAD решения для проектирования трубных конструкций.

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен сборки
npm run preview
```

## 📁 Структура проекта

```
ws/
```

## 🎨 Дизайн

Сайт выполнен в стиле Dotify с:
- Темной цветовой схемой
- Минималистичным дизайном
- Плавными анимациями
- Адаптивной версткой

## 🛠️ Технологии

- **React 18** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик
- **React Router** - роутинг
- **Lucide React** - иконки

## 📄 Страницы

- **/** - Главная страница с hero секцией и возможностями
- **/features** - Подробное описание возможностей
- **/docs** - Документация
- **/download** - Страница загрузки для разных ОС
