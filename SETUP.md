# 🚀 Установка и запуск TubeCAD Website

## Быстрый старт

### 1. Установите Node.js
Скачайте и установите Node.js с официального сайта: https://nodejs.org/
(Рекомендуется версия 18 или выше)

### 2. Установите зависимости
Откройте терминал в папке `igeses/ws` и выполните:

```bash
npm install
```

### 3. Запустите dev сервер
```bash
npm run dev
```

Сайт откроется автоматически по адресу: http://localhost:3000

## 📦 Команды

- `npm run dev` - Запуск dev сервера с hot reload
- `npm run build` - Сборка для продакшена
- `npm run preview` - Предпросмотр продакшен сборки

## 🌐 Деплой

### Vercel (рекомендуется)
1. Зарегистрируйтесь на https://vercel.com
2. Подключите GitHub репозиторий
3. Vercel автоматически соберет и задеплоит сайт

### Netlify
1. Зарегистрируйтесь на https://netlify.com
2. Перетащите папку `dist` после `npm run build`

### GitHub Pages
```bash
npm run build
# Загрузите содержимое папки dist на GitHub Pages
```

## 🐛 Проблемы?

Если что-то не работает:
1. Убедитесь, что Node.js установлен: `node --version`
2. Удалите `node_modules` и `package-lock.json`, затем `npm install`
3. Проверьте, что порт 3000 свободен
4. Проверьте консоль браузера на ошибки
